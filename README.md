# Система управления автосервисом

Курсовой проект на C# / .NET 9. Система предназначена для учета клиентов, автомобилей и заказов на обслуживание в автосервисе.

## Основные возможности в рамках проектируемой версии

- регистрация и редактирование клиентов;
- регистрация автомобилей и связь автомобиля с владельцем;
- создание заказов на обслуживание;
- регистрация выполненных работ;
- учет использованных запчастей;
- расчет стоимости работ и запчастей;
- изменение и просмотр состояния заказа.

На первом этапе подготовлена проектная документация и определены контракты взаимодействия. Реализация приложения, база данных и автоматические тесты будут добавлены на следующих этапах.

## Технологии

- C# / .NET 9;
- ASP.NET Core Web API — предполагаемый HTTP-интерфейс;
- SQLite и Entity Framework Core — предполагаемое хранение данных для учебной версии;
- xUnit — предполагаемое средство модульного тестирования;
- Git — контроль версий.

Конкретные версии NuGet-пакетов будут зафиксированы в `.csproj` при создании решения.

## Сборка и запуск

На момент этапа 1 исполняемое приложение еще не создано, поэтому команды `dotnet build`, `dotnet test` и `dotnet run` пока не могут быть выполнены для решения целиком.

Проверьте установленный SDK:

```bash
dotnet --list-sdks
```

После создания решения и API на следующих этапах инструкция будет дополнена точными командами восстановления, сборки, тестирования и запуска.
