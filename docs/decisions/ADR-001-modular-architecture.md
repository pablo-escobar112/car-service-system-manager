# ADR-001: Модульный монолит

- **Статус:** принято для проектирования; пересмотр возможно при росте требований.
- **Контекст:** учебный проект должен демонстрировать несколько взаимодействующих модулей, при этом оставаться воспроизводимым на локальном компьютере.
- **Решение:** использовать одно приложение ASP.NET Core с отдельными логическими модулями и публичными контрактами.
- **Альтернативы:** микросервисы с отдельными процессами и сетевым взаимодействием; единый проект без разделения ответственности.
- **Обоснование:** модульный монолит проще запускать и тестировать, чем несколько сетевых сервисов, но он позволяет изолировать бизнес-правила и проверять межмодульные контракты.
- **Последствия:** модули запускаются вместе; границы должны соблюдаться на уровне проектов/пространств имен и интерфейсов. При необходимости модули можно выделить отдельно позже.
