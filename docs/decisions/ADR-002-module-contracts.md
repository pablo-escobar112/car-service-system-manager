# ADR-002: Явные контракты взаимодействия

- **Статус:** принято.
- **Контекст:** заказ должен взаимодействовать с учетом клиентов, автомобилей, работ, запчастей и расчетом стоимости. Прямое использование внутренних классов соседнего модуля усложнит интеграцию.
- **Решение:** использовать публичные интерфейсы прикладных сервисов и DTO из `CarService.Contracts`. Для внешнего взаимодействия API использует HTTP/JSON.
- **Альтернативы:** прямое обращение к внутренним классам; передача сущностей хранения данных через API.
- **Обоснование:** контракты делают ожидаемые входы, выходы и ошибки явными и упрощают модульные и интеграционные тесты.
- **Последствия:** изменение контракта требует проверки всех потребителей и обновления тестов/документации. DTO не должны без необходимости раскрывать внутреннюю структуру базы данных.
