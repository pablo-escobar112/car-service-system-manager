# Стратегия тестирования

## 1. Цель

Проверить правила предметной области, взаимодействие модулей и публичные HTTP-контракты. На этапе 1 перечислены планируемые проверки; результаты выполнения тестов появятся только после реализации.

## 2. Модульные тесты

| Область | Проверка | Ожидаемый результат |
|---|---|---|
| Расчет стоимости | 2 работы по 50.00 и 1 запчасть 20.00 × 3 | Итог 160.00 |
| Расчет стоимости | Пустой заказ | Итог 0.00 |
| Запчасти | Количество равно 0 | Ошибка валидации |
| Запчасти | Отрицательная цена | Ошибка валидации |
| Статусы | `Created` → `InProgress` | Переход разрешен |
| Статусы | `Issued` → `InProgress` | Переход отклонен |
| Создание заказа | Клиент не существует | `CUSTOMER_NOT_FOUND` |
| Создание заказа | Автомобиль принадлежит другому клиенту | `VEHICLE_OWNER_MISMATCH` |

## 3. Интеграционные тесты

1. Создание заказа для существующих клиента и автомобиля возвращает `201`, а заказ сохраняется.
2. Создание заказа с неизвестным автомобилем возвращает ожидаемую ошибку и не создает заказ.
3. Добавление работы увеличивает сумму работ и итог заказа.
4. Добавление запчасти учитывает количество и цену за единицу.
5. Изменение статуса на допустимый успешно сохраняет новое состояние.
6. Недопустимый переход статуса отклоняется.
7. После закрытия заказа изменение состава заказа запрещено.

## 4. Проверки API

При наличии ASP.NET Core API планируется проверять:
- HTTP-статусы;
- структуру JSON;
- обязательные поля;
- устойчивые коды ошибок;
- отсутствие утечки внутренних исключений в ответ клиенту.

## 5. Критерии завершения проверки

- решение собирается без ошибок;
- все автоматические тесты проходят;
- каждый протокол имеет успешный и отрицательный сценарий;
- ручные проверки документированы, если автоматизация пока отсутствует;
- неуспешные результаты не скрываются, а записываются вместе с причиной.

## 6. Команды после создания решения

```bash
dotnet restore
dotnet build
dotnet test
```

На текущем этапе полноценного решения еще нет, поэтому нельзя заявлять, что эти команды уже успешно выполнялись.
